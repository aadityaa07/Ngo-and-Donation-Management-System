# CareConnect (JS only version)

No installation needed: just open `index.html` in your browser.

- Data is saved in your browser (localStorage), so it stays on your own computer.
- Admin login page: admin-login.html  (admin@careconnect.org / admin123). Donors use login.html.
- Start fresh: open DevTools (F12) > Application > Local Storage > Clear.
