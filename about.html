About the Project

CareConnect is a frontend prototype for an NGO and Donation Management System.

Why this system?

NGOs may have to manage donor information, campaigns, donations, volunteers, and beneficiaries across different records. This project presents a simple interface for bringing important information into one place.

Project Goals

The system focuses on clear donor forms, cause browsing, donation records, and an administrative overview while keeping the current implementation simple and easy to understand.

Current Scope

This version is a static frontend built with HTML and CSS. Authentication, database storage, payment processing, and other dynamic features can be connected in future development.
